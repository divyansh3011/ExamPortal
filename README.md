# ExamPortal

> A web-based examination portal designed to simplify and manage the online examination process for students and administrators.

## Overview

**ExamPortal** is a web-based examination management system that provides separate interfaces for students and administrators.

The platform is designed to make online examinations easier to conduct by providing dedicated student and admin sections, authentication pages, and a structured frontend/backend architecture.

## Features

* Student portal for accessing examination-related features
* Admin portal for managing the examination system
* Login and authentication interface
* Separate frontend and backend structure
* Organized CSS and JavaScript files
* Simple and user-friendly web interface
* Modular project structure for easier development and maintenance

## Project Structure

```text
ExamPortal/
│
├── admin/          # Admin-side functionality
├── backend/        # Backend/server-side functionality
├── css/             # Stylesheets
├── frontend/        # Frontend components/pages
├── js/              # JavaScript files
├── student/         # Student-side functionality
│
├── index.html       # Main entry page
├── login.html       # Login page
│
└── README.md        # Project documentation
```

## User Roles

### Student

Students can use the portal to access the examination-related functionality provided by the system.

### Administrator

Administrators have access to the management side of the portal for handling examination-related operations.
